# Release Notes - v1.1.2.8

## 🚀 What's New
- **Automated Build & Publishing CLI**: Streamlined local and remote package releases using a standardized CLI tool in `main.py`.
- **Pre-Publishing Verification Guard**: Automatically updates README version badges before upload and rolls them back to the latest online version on PyPI or TestPyPI if the upload fails.
- **GitHub Release Integration**: Unified PyPI package delivery with local git tag curation and formal GitHub Release creation, paired with automated build artifact asset uploads.
- **Centralized GFM Task Checklists**: Isolated active backlog items from guidelines and progress logs into an interactive `TASKS.md` board.
- **Enterprise GitHub Issue Templates**: Formulated industry-standard issue templates for bug tracking, feature requests, and refactoring tasks.
